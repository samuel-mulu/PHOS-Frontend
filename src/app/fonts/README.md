# Bundled fonts

`GeistVF.woff2` and `GeistMonoVF.woff2` are the Geist and Geist Mono variable fonts
(weights 100–900, Latin subset). They are loaded with `next/font/local` in
`src/app/layout.tsx`, so `npm run build` works without internet access.
